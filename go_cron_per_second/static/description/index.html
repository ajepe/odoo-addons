Run Your Cron Jobs Every Second

Take Odoo's scheduled actions to the next level with second-level precision. Configure cron jobs to run every second — or at any other interval measured in seconds.

Overview

By default, Odoo's Scheduled Actions can only repeat every minute, hour, day, week or month. This module extends the standard scheduler with a Seconds interval unit, so any cron job can be configured to run every second — or every N seconds.

It integrates directly with the Scheduled Actions you already use: no new interface to learn, no separate job runner, no code changes required.

Key Features

  • Second-level cron intervals — add a new "Seconds" unit to the Interval Unit selection.
  • Run every 1 second — the shortest scheduling granularity available in Odoo.
  • Fully configurable — combine any positive number of seconds with your action.
  • Native integration — configured through the regular Scheduled Actions form.
  • Simple configuration — install, then pick the interval; no development needed.
  • Safe for existing jobs — current cron jobs keep their behavior unchanged.
  • Built for frequent tasks — suited to lightweight actions that must run often.

How It Works

Odoo stores each scheduled action's repeat interval as a number plus a unit. This module registers an additional unit ("Seconds") and teaches the scheduler how to apply it when computing the next execution date of a job. It also keeps the scheduler responsive enough to honor one-second cadences.

A scheduled action configured like this runs approximately every second:

Interval Number: 1
Interval Unit:   Seconds

Execution happens at approximately one-second intervals, subject to your server's worker count, scheduler load and the duration of the action itself.

Useful whenever integrations or processes require frequent, lightweight scheduled processing, for example:

  • Near real-time data synchronization between systems
  • Fast queue processing (pick up queued items as soon as they arrive)
  • Polling external APIs for status changes (payments, shipments, documents)
  • IoT integrations that push readings at short intervals

The module provides the scheduling mechanism only — it does not include synchronization, queueing or monitoring systems themselves.

Configuration Example

To run a scheduled action every second:

  1. Open Settings > Technical > Automation > Scheduled Actions.
  2. Create a new scheduled action (or edit an existing one).
  3. Set Execute Every to 1.
  4. Select Seconds in the Interval Unit dropdown.
  5. Choose the model and write the action code (Python code, or another action type), then activate the record.

For a five-second cadence, set Execute Every = 5 with the same unit. The next execution date shown on the record always reflects your configuration.

Performance Considerations

⚠️ Important

A cron job that runs every second can significantly increase server and database workload. Before enabling second-level execution, carefully evaluate:

  • CPU usage generated by the repeated executions
  • Database workload created by each run
  • The total number of scheduled actions running at short intervals
  • The execution time of the method being called — it should complete well within the interval
  • The frequency of external API calls triggered by the action (rate limits and costs)

Keep second-level execution for genuinely time-sensitive, fast operations only. For heavy processing, prefer larger intervals or a dedicated job-queue solution.

Compatibility

For Developers

Developers can rely on second-level scheduling for time-sensitive background processes while continuing to use Odoo's standard scheduled-action mechanism: define an ir.cron record as usual, set interval_number and choose 'seconds' as interval_type. Everything else — activation, logging, failure handling and manual triggering — behaves exactly like any other scheduled action.

FAQ

Can I run a cron every second?

Yes. Set Interval Number = 1 and Interval Unit = Seconds; the scheduler will target a one-second cadence.

Can I use intervals other than one second?

Yes. Any positive whole number of seconds is supported: 1, 2, 5, 10 seconds and so on.

Will existing Odoo cron jobs continue working?

Yes. The module only adds a new interval unit option. Existing scheduled actions keep their original intervals and are not affected by installation or uninstallation.

Does this replace Odoo's Scheduled Actions?

No. It extends the existing Scheduled Actions feature rather than introducing a separate scheduler. You configure everything in the familiar place under Settings > Technical.

Is execution exactly on the second?

No. Runs are targeted at the configured cadence but are subject to normal scheduler behavior: available workers, other running jobs and the duration of previous runs. Treat the interval as "approximately every N seconds".

Can I use it for heavy background processing?

It is not recommended. Frequent execution multiplies whatever work the action performs. For heavy jobs, keep longer intervals or use a dedicated asynchronous job queue solution, and reserve second-level execution for quick, lightweight operations.
