Cron Per Second
===============

Overview
--------

By default, Odoo's Scheduled Actions can only repeat every minute, hour, day,
week or month. This module extends the standard scheduler with a **Seconds**
interval unit, so any cron job can be configured to run every second — or
every N seconds.

It integrates directly with the Scheduled Actions you already use: no new
interface to learn, no separate job runner and no code changes required.

Key Features
------------

* Second-level cron intervals (new "Seconds" Interval Unit)
* Run scheduled actions every 1 second
* Any positive whole number of seconds (1, 2, 5, 10, ...)
* Configured through the regular Odoo Scheduled Actions form
* Existing cron jobs keep their behavior unchanged
* Suited to lightweight actions that must run frequently

How It Works
------------

Odoo stores each scheduled action's repeat interval as a number plus a unit.
This module registers an additional unit ("Seconds") and teaches the scheduler
how to apply it when computing the next execution date of a job. It also keeps
the scheduler responsive enough to honor one-second cadences.

A scheduled action configured like this runs approximately every second::

    Interval Number: 1
    Interval Unit:   Seconds

Execution happens at approximately one-second intervals, subject to your
server's worker count, scheduler load and the duration of the action itself.
Execution is not guaranteed to be exactly on the second.

Use Cases
---------

Useful whenever integrations or processes require frequent, lightweight
scheduled processing, for example:

* Near real-time data synchronization between systems
* Fast queue processing
* Polling external APIs (payments, shipments, documents)
* IoT integrations pushing readings at short intervals
* Live metrics collection
* Time-sensitive notifications
* Monitoring external systems from within Odoo

The module provides the scheduling mechanism only; it does not include the
synchronization, queueing or monitoring systems themselves.

Configuration Example
---------------------

To run a scheduled action every second:

#. Open *Settings > Technical > Automation > Scheduled Actions*.
#. Create or edit a scheduled action.
#. Set *Execute Every* to ``1``.
#. Select *Seconds* in the *Interval Unit* dropdown.
#. Choose the model and write the action code, then activate the record.

For a five-second cadence, set *Execute Every = 5* with the same unit.

Performance Considerations
--------------------------

.. warning::

   A cron job that runs every second can significantly increase server and
   database workload. Before enabling second-level execution, evaluate:

   * CPU usage generated by the repeated executions
   * Database workload created by each run
   * The number of scheduled actions running at short intervals
   * The execution time of the method being called (it should complete well
     within the interval)
   * The frequency of external API calls triggered by the action

   Keep second-level execution for genuinely time-sensitive, fast operations
   only. For heavy processing, prefer larger intervals or a dedicated
   job-queue solution.

Compatibility
-------------

The module follows Odoo's standard versioning scheme: install the release
matching your Odoo version (see the version selector on the Apps Store). It
depends only on Odoo's base framework.

Developer Information
---------------------

Developers can use second-level scheduling for time-sensitive background
processes while continuing to use Odoo's standard scheduled-action mechanism:
define an ``ir.cron`` record as usual, set ``interval_number`` and choose
``'seconds'`` as ``interval_type``. Activation, logging, failure handling and
manual triggering behave exactly like any other scheduled action.

FAQ
---

**Can I run a cron every second?**
Yes. Set *Interval Number = 1* and *Interval Unit = Seconds*.

**Can I use intervals other than one second?**
Yes. Any positive whole number of seconds is supported.

**Will existing Odoo cron jobs continue working?**
Yes. The module only adds a new interval unit option; existing scheduled
actions keep their original intervals.

**Does this replace Odoo's Scheduled Actions?**
No. It extends the existing mechanism rather than introducing a separate
scheduler.

**Is execution exactly on the second?**
No. Runs target the configured cadence but remain subject to normal scheduler
behavior (workers, load, previous runs still executing).

**Can I use it for heavy background processing?**
Not recommended. For heavy jobs keep longer intervals or use a dedicated
asynchronous job queue solution.
